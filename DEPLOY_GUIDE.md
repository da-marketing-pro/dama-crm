## 1. Аренда VPS-сервера на Hetzner Cloud

Hetzner Cloud — надежный немецкий облачный провайдер с отличными ценами (от €4 до €8 в месяц) и низким пингом для Казахстана и СНГ.

### Шаг 1.1: Регистрация и верификация
1. Перейдите на сайт [hetzner.com/cloud](https://www.hetzner.com/cloud) и нажмите **«Sign up»**.
2. Заполните данные профиля (имя, фамилия, контактный телефон, адрес в Казахстане).
3. **Оплата картой Visa казахстанского банка:**
   * В разделе биллинга привяжите банковскую карту Visa (Kaspi Gold, Halyk Bank, Jusan, Freedom Bank, Forte и др.).
   * *Важно:* Убедитесь в мобильном приложении банка, что для карты открыт лимит на интернет-покупки (при верификации банк может временно заблокировать и сразу вернуть сумму около 1–2 евро для проверки активности).
4. Пройдите стандартную быструю верификацию личности (KYC), если система запросит подтверждение (обычно фото загранпаспорта/ID-карты через камеру телефона).

### Шаг 1.2: Создание сервера
1. Войдите в консоль [console.hetzner.cloud](https://console.hetzner.cloud).
2. Нажмите **«+ New Project»**, назовите проект (например, `DAMA-CRM`).
3. Внутри проекта нажмите красную кнопку **«Add Server»**.
4. Выберите параметры:
   * **Location (Локация):** `Falkenstein` или `Nuremberg` (Германия) или `Helsinki` (Финляндия).
   * **Image (Операционная система):** `Ubuntu 24.04 LTS` (рекомендуется) или `Ubuntu 22.04 LTS`.
   * **Type:** `Shared vCPU (x86 / Intel / AMD)`.
   * **Тарифный план:**
     * **CX22** (2 vCPU, 4 GB RAM, 40 GB NVMe) — ~€4.35/месяц (подходит для старта);
     * **CX32** (4 vCPU, 8 GB RAM, 80 GB NVMe) — ~€8.00/месяц (**Рекомендуется** для одновременной быстрой работы CRM, базы PostgreSQL, Redis, Evolution API WhatsApp и фоновой сборки обновлений).
   * **Networking:** Оставьте включенным `Public IPv4` (он понадобится для привязки домена).
   * **SSH Keys:** Если у вас есть ключ SSH — добавьте его. Если нет — Hetzner сгенерирует пароль суперпользователя `root` и отправит его вам на email.
   * **Name (Имя сервера):** `dama-crm-vps`.
5. Нажмите внизу кнопку **«Create & Buy Now»**.
6. Сервер развернется за 20–30 секунд. В списке серверов скопируйте его **IPv4 адрес** (например: `95.217.123.45`).

## 2. Установка панели управления Coolify

**Coolify** — это современная панель управления (аналог облачных сервисов Heroku и Vercel, но на вашем личном сервере). Она берет на себя управление Docker-контейнерами, базами данных, выпуском бесплатных SSL-сертификатов и деплоем из GitHub.

### Шаг 2.1: Подключение к серверу по SSH
1. На компьютере Mac откройте стандартное приложение **«Терминал»** (Terminal). На Windows используйте PowerShell или Windows Terminal.
2. Введите команду для подключения к вашему серверу:
   ```bash
   ssh root@ВАШ_IP_СЕРВЕРА
   ```
   *(Замените `ВАШ_IP_СЕРВЕРА` на скопированный IP от Hetzner, например: `ssh root@95.217.123.45`)*.
3. При первом подключении появится вопрос: `Are you sure you want to continue connecting (yes/no/[fingerprint])?` — напишите `yes` и нажмите Enter.
4. Введите пароль `root` (из письма от Hetzner) и нажмите Enter (при вводе пароля символы в терминале не отображаются из соображений безопасности — это нормально).

### Шаг 2.2: Запуск установки Coolify одной командой
Вставьте в терминал команду и нажмите Enter:
```bash
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
```
*Установка займет около 2–4 минут.* Скрипт сам настроит Docker, Docker Compose, обратный прокси-сервер Traefik и панель Coolify.

### Шаг 2.3: Первый вход в Coolify
1. Откройте браузер и перейдите по адресу:
   ```text
   http://ВАШ_IP_СЕРВЕРА:8000
   ```
2. Откроется окно регистрации первого пользователя. Введите ваш рабочий email и надежный пароль администратора.
3. Нажмите **«Register»**. Поздравляем, панель установлена!

## 3. Настройка поддомена и автоматический SSL

Чтобы не затрагивать работу основного сайта вашего агентства (например, `agency.kz`), мы настраиваем для CRM отдельный изолированный поддомен (например, `crm.agency.kz`).

### Шаг 3.1: Создание A-записи в DNS регистратора домена
Зайдите в панель управления тем сервисом, где куплен ваш домен (PS.kz, Cloudflare, Reg.ru, Namecheap, GoDaddy или др.):
1. Откройте раздел **«Управление DNS»** (DNS Management / Редактор DNS-зоны).
2. Нажмите **«Добавить запись»** (Add Record).
3. Укажите следующие параметры:
   * **Тип записи (Type):** `A`
   * **Имя поддомена (Name / Host):** `crm` *(если ваш домен `agency.kz`, в итоге получится адрес `crm.agency.kz`)*
   * **Значение / IP (Target / IPv4):** Вставьте `IPv4 адрес вашего сервера Hetzner` (например: `95.217.123.45`).
   * **TTL:** `300` или `Auto` / `1 час`.
4. Для WhatsApp сервиса создайте аналогичную вторую A-запись:
   * **Тип записи:** `A`
   * **Имя:** `wa` *(получится `wa.agency.kz`)*
   * **Значение:** Тот же самый `IPv4 адрес сервера Hetzner`.
5. Сохраните изменения. DNS-записи обновляются в течение 5–15 минут.

> [!NOTE]
> Основной сайт агентства (`agency.kz` и `www.agency.kz`) продолжит работать без малейших изменений и останется на своем прежнем хостинге. Создание поддомена `crm` полностью изолировано.

### Шаг 3.2: Привязка домена в Coolify и авто-HTTPS
1. В интерфейсе Coolify при настройке приложения в поле **Domains** укажите:
   ```text
   https://crm.agency.kz
   ```
2. Coolify автоматически свяжется с сервисом Let's Encrypt и в течение 30 секунд выпустит официальный, доверенный **SSL-сертификат** (замочек в браузере).

> [!IMPORTANT]
> **Почему HTTPS критически важен для CRM:**
> Браузеры (Google Chrome, Apple Safari, Яндекс Браузер) из соображений конфиденциальности блокируют доступ к микрофону на сайтах без защищенного протокола HTTPS. Наличие `https://` гарантирует, что менеджеры смогут без ограничений записывать и отправлять голосовые аудиосообщения клиентам прямо из браузера!

## 4. Подключение GitHub и настройка CI/CD

Благодаря связке GitHub + Coolify вы получаете полноценную систему непрерывного деплоя (CI/CD): как только код обновлен в репозитории, сервер автоматически собирает новую версию без участия программиста и без ручных перезагрузок.

### Шаг 4.1: Создание приватного репозитория на GitHub
1. Зайдите в свой аккаунт на [github.com](https://github.com).
2. В правом верхнем углу нажмите значок **«+»** -> **«New repository»**.
3. Заполните поля:
   * **Repository name:** `dama-crm`
   * **Приватность:** Обязательно выберите **Private** (Приватный, чтобы исходный код и бизнес-логика были доступны только вам).
   * **Не ставьте галочки** на «Add a README file» или «Add .gitignore» (эти файлы уже настроены в нашей рабочей папке).
4. Нажмите зеленую кнопку **«Create repository»**.
5. Скопируйте ссылку на ваш новый репозиторий (например: `https://github.com/ваш-логин/dama-crm.git`).

### Шаг 4.2: Первая отправка кода в GitHub
Откройте терминал на вашем локальном компьютере в папке проекта CRM и выполните 3 команды:
```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/dama-crm.git
git branch -M main
git push -u origin main
```
*(Если GitHub запросит авторизацию, войдите через браузер или Personal Access Token)*. Код отправлен в ваш приватный репозиторий!

### Шаг 4.3: Подключение репозитория в Coolify
1. В левом меню Coolify откройте раздел **«Sources»** -> выберите **«GitHub App»**.
2. Нажмите кнопку подключения: Coolify предложит авторизовать официальное приложение Coolify в вашем GitHub-аккаунте и выбрать репозиторий `dama-crm`.
3. Вернитесь в раздел **«Projects»** -> выберите ваш проект -> нажмите **«+ New Resource»**.
4. Выберите **«Application»** -> **«GitHub Repository»**.
5. Выберите репозиторий `dama-crm` и ветку `main`.
6. **Тип сборки (Build Pack):** Выберите **Docker Compose** и укажите файл `docker-compose.prod.yml`.
7. **Переменные окружения (Environment Variables):**
   Нажмите на вкладку **«Environment Variables»** и укажите боевые переменные (на основе файла `.env.example`):
   ```ini
   NEXTAUTH_URL=https://crm.agency.kz
   NEXTAUTH_SECRET=сгенерируйте_ключ_например_openssl_rand_base64_32
   CRON_SECRET=dama_crm_cron_secret_token_secure_9921
   ADMIN_INITIAL_EMAIL=admin@crm.local
   ADMIN_INITIAL_PASSWORD=придумайте_надежный_пароль_админа
   DB_USER=crm_user
   DB_PASSWORD=надежный_пароль_к_базе_данных_2026
   DB_NAME=crm_db
   EVOLUTION_API_KEY=надежный_ключ_для_whatsapp_evo_2026
   ```
8. Включите переключатель **«Instant Deploy (Auto Deploy on push)»**.
9. Нажмите кнопку **«Deploy»**. 

### Шаг 4.4: Как обновлять проект через ИИ-агента Antigravity
Вам больше никогда не придется заходить на удаленный сервер! Весь процесс обновления происходит предельно просто:
1. Вы формулируете задачу агенту Antigravity на локальном компьютере: *«Добавь новый виджет в аналитику»* или *«Измени цвет статуса воронки»*.
2. Агент вносит изменения и проверяет работоспособность.
3. Вы говорите агенту: **«Отправь изменения на GitHub»**.
4. Агент выполняет команду `git push`.
5. GitHub через защищенный вебхук уведомляет Coolify -> Coolify автоматически скачивает обновления, собирает контейнер и без простоя (Zero Downtime) обновляет сайт `https://crm.agency.kz`.

## 5. Развертывание WhatsApp (Evolution API v2)

В нашем файле `docker-compose.prod.yml` сервис **Evolution API v2** уже полностью сконфигурирован вместе с Redis и подключением к PostgreSQL.

### Шаг 5.1: Привязка номера WhatsApp в CRM
1. Перейдите в браузере в установленную CRM по адресу `https://crm.agency.kz` и авторизуйтесь под администратором.
2. В левом сайдбаре откройте **«Настройки»** -> подраздел **«Интеграция WhatsApp»** (URL: `/settings/whatsapp`).
3. Проверьте настройки подключения:
   * **URL инстанса:** `http://evolution-api:8080` (внутренний адрес в сети Docker) или ваш внешний адрес `https://wa.agency.kz`.
   * **API Key:** Значение переменной `EVOLUTION_API_KEY`, которую вы указали в переменных Coolify.
4. Нажмите кнопку **«Создать инстанс и получить QR-код»**.
5. На экране появится актуальный QR-код для привязки.
6. Возьмите корпоративный смартфон с WhatsApp:
   * Откройте WhatsApp -> перейдите в **«Настройки»** -> **«Связанные устройства»** (Linked Devices).
   * Нажмите **«Привязка устройства»** и отсканируйте камерой QR-код на экране монитора.
7. Статус в CRM сменится на зеленый индикатор: **«Подключено»**.

### Шаг 5.2: Проверка работы входящих и исходящих сообщений
1. На странице настроек WhatsApp нажмите кнопку **«Симулятор входящего сообщения»** или отправьте реальное текстовое сообщение с любого личного номера на рабочий номер WhatsApp.
2. В DAMA CRM мгновенно:
   * Создастся новый клиент в разделе **«Контакты»**;
   * Появится новая карточка сделки на 1-м этапе воронки продаж;
   * В разделе **«WhatsApp»** откроется живой чат, откуда менеджер может отвечать клиенту текстом или голосовыми сообщениями.

## 6. Настройка автоматического обновления курсов валют

По требованию системы, курсы USD и RUB по отношению к KZT должны автоматически обновляться **1-го числа каждого месяца** на основе среднего арифметического курса за прошедшие 2 месяца (60 дней).

В CRM уже заложен защищенный маршрут: `/api/cron/update-rates`. Для автоматического вызова по расписанию настроим задачу в Coolify:

1. В панели Coolify откройте ваше приложение **DAMA CRM**.
2. В верхнем меню приложения выберите вкладку **«Scheduled Tasks»** (или Cron Jobs).
3. Нажмите **«+ Add Task»**.
4. Заполните параметры задачи:
   * **Name (Название):** `Monthly Currency Rates 60-days Sync`
   * **Frequency / Schedule (Расписание Cron):**
     ```text
     0 0 1 * *
     ```
     *(Это означает: ровно в 00:00, 1-го числа каждого месяца).*
   * **Command (Команда для выполнения):**
     ```bash
     curl -s -X POST https://crm.agency.kz/api/cron/update-rates -H "Authorization: Bearer dama_crm_cron_secret_token_secure_9921"
     ```
     *(Вместо `dama_crm_cron_secret_token_secure_9921` используйте значение вашего `CRON_SECRET`)*.
5. Нажмите кнопку **«Save»**.
6. **Проверка работоспособности:**
   * В списке созданных задач нажмите кнопку **«Run Now»** (Выполнить сейчас).
   * Откройте журнал выполнения (Logs): вы увидите ответ сервера `200 OK` с рассчитанными средними котировками за 60 дней.
   * При этом исторические данные по прошлым сделкам и траншам оплат останутся в полной сохранности.

## 7. Чек-лист безопасности и запуск в работу

Перед передачей системы в отдел продаж выполните 4 финальных шага:

- [x] **Шаг 1: Смена пароля администратора**
  Войдите в систему и в разделе пользователей измените временный пароль учетной записи `admin@crm.local` на надежный постоянный пароль.
- [x] **Шаг 2: Добавление менеджеров отдела продаж**
  В разделе **«Настройки»** -> **«Сотрудники»** создайте учетные записи для менеджеров с ролью `MANAGER`. Менеджеры увидят только свои сделки, контакты и задачи, а финансовые настройки и удаление данных останутся закрытыми.
- [x] **Шаг 3: Настройка автоматических бэкапов в Coolify**
  В Coolify в карточке базы данных PostgreSQL откройте вкладку **«Backups»**, укажите периодичность (например, каждый день в 03:00 ночи) и сохраняйте резервные копии.
- [x] **Шаг 4: Тест голосовых сообщений**
  Откройте карточку любого контакта в браузере, запишите через микрофон короткое аудиосообщение и нажмите «Отправить». Убедитесь, что аудиосообщение доставлено и проигрывается через встроенный плеер.
